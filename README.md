# ZABANGRAM AI MANAGER

نسخه اولیه داشبورد تحلیل ویدئوهای آپارات و اینستاگرام.

## وضعیت فعلی
- رابط فارسی و راست‌چین آماده است.
- امکان بارگذاری فایل ویدئویی در نسخه اولیه وجود دارد.
- اتصال واکشی خودکار لینک‌ها و تحلیل هوش مصنوعی هنوز پیاده‌سازی نشده است.
- این نسخه برای راه‌اندازی اولیه روی Hugging Face Spaces با Docker آماده شده است.
